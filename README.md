# PAJO TECNOLOGIA — Site Institucional

Site institucional da **PAJO TECNOLOGIA**, com apresentação da empresa e catálogo das soluções.

## Estrutura

```
sitepajo/
├── index.html
├── sistemas/
│   ├── pjzap.html
│   ├── sgh.html
│   ├── ezpoint.html
│   ├── imob.html
│   ├── sgl.html
│   └── pajotech-tree.html
├── style.css
├── app.js
└── assets/
    └── logo-pajo.png
```

## Sistemas

Cada solução possui uma página institucional própria no diretório `sistemas/`, com descrição objetiva, recursos, contato e CTA para o respectivo portal:

| Sistema | Página institucional | Portal |
| :--- | :--- | :--- |
| **PJZap** | `sistemas/pjzap.html` | https://pjzap.pajotech.com.br |
| **SGH** | `sistemas/sgh.html` | https://sgh.pajotech.com.br |
| **EzPoint Web** | `sistemas/ezpoint.html` | https://ponto.pajotech.com.br |
| **IMOB** | `sistemas/imob.html` | https://imob.pajotech.com.br |
| **SGL Lavanderia** | `sistemas/sgl.html` | https://sgl.pajotech.com.br |
| **Pajotech Tree** | `sistemas/pajotech-tree.html` | https://tree.pajotech.com.br |

A página inicial funciona como catálogo institucional e direciona o visitante para a página específica de cada solução, evitando URLs repetidas e CTAs redundantes.
